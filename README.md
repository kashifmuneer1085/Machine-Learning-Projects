# Machine Learning Projects

A collection of practical Machine Learning projects developed using Python, NumPy, Pandas, Matplotlib, and Scikit-learn.

The purpose of this repository is to apply Machine Learning concepts to real-world problems while developing a strong understanding of their mathematical foundations and practical implementation.

## Projects

### 1. Simple Linear Regression

- House Price Prediction
- Student Marks Prediction

### 2. Multiple Linear Regression

- Employee Salary Prediction
- House Price Prediction

### 3. Polynomial Regression

- Used Car Price Prediction
- Electricity Consumption Prediction

### 4. Logistic Regression

- Loan Default Prediction
- Employee Attrition Prediction

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Learning Approach

Each project includes:

- Exploratory Data Analysis
- Data Preprocessing
- Feature Engineering
- Model Implementation from Scratch
- Scikit-learn Implementation
- Model Evaluation
- Visualizations
- Conclusions and Observations
